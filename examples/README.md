# examples

Runnable client examples for applications that call Tamiz. They are workspace packages,
so CI lints, typechecks and tests them against the gateway's E2E harness, but Tamiz does
not ship them: they show how an application talks to Tamiz. Today there is one,
[`citara-client/`](citara-client/) (feature 010, guide in `docs/integrations/citara.md`).
